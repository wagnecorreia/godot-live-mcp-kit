# Snippet para colar no AGENTS.md do seu projeto Godot

```markdown
## Ferramentas de desenvolvimento
- Integração ao vivo com o editor: carregue a skill **`godot-live`** antes de usar ferramentas `godot_*`.
- Reinstalar a ponte: `powershell -ExecutionPolicy Bypass -File tools/setup-godot-mcp.ps1`
- Referência de API da engine: `%LOCALAPPDATA%\godot-api\<versao>` (regenerar com `tools/dump-godot-api.ps1`).
- `opencode.json` usa o formato V2: servidores em `mcp.servers`.
```
